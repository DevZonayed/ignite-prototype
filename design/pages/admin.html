Lesson framing

Edit
Real-world problem — How can we build a reading lamp that turns on when we press a button?
Big idea — A robot follows instructions to solve real-life problems.
Essential question — How can we use a button, an LED and Arduino to build a smart reading lamp?

Learning outcomes

Edit
Build a Smart Reading Lamp.
Connect electronic components correctly.
Write a simple PictoBlox program.
Upload the program to Arduino.
Test their invention & explain how it works.

Success criteria

Edit
I built my first invention.
My lamp works.
I can explain the program.
I can identify the input and the output.

Teacher coaching notes

Edit
First complete engineering experience — focus on the process, not just a working project. Reinforce the routine:
1 Problem
2 Input
3 Brain
4 Output
5 Build
6 Program
7 Test
8 Improve
9 Explain
If a project fails, teach debugging rather than fixing it — check wiring, review the program, test one step at a time.
